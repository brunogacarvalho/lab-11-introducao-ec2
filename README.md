# Lab 11 - Introdução ao Amazon EC2

## Objetivo

Documentar a criação e configuração de uma instância Amazon EC2 para hospedar um servidor web na AWS.

## Atividades do laboratório

- Criação de uma instância EC2 com Amazon Linux 2023.
- Configuração de grupos de segurança para acesso HTTP.
- Instalação e execução do servidor web Apache.
- Redimensionamento da instância e do volume EBS.
- Teste da proteção contra encerramento da instância.

## Experimentos adicionais

### User Data

Investigação do comportamento do User Data após alterações no script e reinicialização da instância.

### Acesso remoto com PuTTY

Conexão à instância por SSH e atualização manual dos arquivos do servidor web.

### Página web personalizada

Criação de uma página HTML com CSS para apresentar os estudos práticos em Cloud Computing.

## Evidências

As capturas de tela registram as configurações, os testes e os resultados observados durante as atividades.

## Tecnologias utilizadas

- Amazon EC2
- Amazon Linux 2023
- Amazon EBS
- Security Groups
- Apache HTTP Server
- Linux, SSH e PuTTY
- HTML e CSS

## Observação

As atividades estão organizadas entre o laboratório original do curso e os experimentos adicionais realizados para aprofundar o aprendizado.
